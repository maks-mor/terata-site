# Terata Corporate Website

Официальный сайт проекта **Terata** (FSIF — First Stage Idea Foundry).

## Стек технологий
* **Frontend:** React 19, TypeScript
* **Сборщик:** Vite
* **Стили:** Tailwind CSS v4, Lucide Icons
* **Шрифты:** Manrope, JetBrains Mono

## Локальная разработка

```bash
# Установка зависимостей
npm install

# Запуск сервера разработки
npm run dev

# Проверка типов
npm run build
```
